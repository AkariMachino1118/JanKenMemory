# ジャンケン帳（複数人リアルタイム版）

メンバーが自由に増減でき、各自が自分の端末（スマホ）から自分のIDでログインして
じゃんけんの手を送信できる、共有じゃんけん記録アプリです。

- ログイン不要でURLを知っている人なら誰でも「閲覧」できます
- 「参加」するとID（短いコード）が発行され、そのIDで自分の端末から手を送信できます
- 過去のExcel（上田・小林・吉村の記録）はそのまま初期データとして自動で読み込まれます
- 裏側はFirebase無料枠（Firestore + 匿名認証）、公開先はGitHub Pagesを想定しています

## セットアップ手順

Firebaseプロジェクト（Firestore・匿名認証・`firebase-config.js`への設定値反映）は
すでに完了しています。残るのは公開設定のみです。

### 1. GitHub Pages で公開する
1. このリポジトリ →「Settings」→「Pages」
2. 「Source」を「Deploy from a branch」にし、ブランチ `main`・フォルダ `/ (root)` を選んで保存
3. しばらくすると `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセス可能になります

### 2. FirebaseにPagesのドメインを許可する
1. Firebaseコンソール →「Authentication」→「Settings」→「承認済みドメイン」
2. `<ユーザー名>.github.io` を追加

以上で完了です。上記のURLをLINEなどでメンバーに共有してください。

## 使い方

- 最初のメンバー（上田・小林・吉村）は過去データと一緒に自動登録済みです。
  ログインIDはそれぞれ 上田`2107` / 小林`2111` / 吉村`2152` です。
- 新しく参加する人は「はじめて参加する」タブから表示名と好きな数字ID（他の人と重複しないもの）
  を入力して登録します。**そのIDは他人には教えず、本人が保管してください。**
- 別の端末で使うときは「IDでログイン」からそのIDを入力するだけです。
- 「メンバー」欄からいつでもメンバーを追加・脱退（一時的に対戦対象から外す）できます。
  脱退しても過去の記録は消えません。
- 「対戦」欄で参加者にチェックを入れて開始すると、まだ手を出していない人の分は
  誰の端末からでも入力できます（1人がまとめて代理入力してもOKです）。
  本人が自分のIDでログインして自分の手を入力した場合は、代理入力があっても
  そちらが優先されて上書きされます。全員分が揃うと自動で判定され、
  複数人が同じ手をあいこで出した場合はあいこ、2種類に分かれた場合は
  負けている方だけで再戦（勝ち抜け発生）を繰り返し、最後の1人になったら
  その回の負けとして記録されます。

## シーズン

- 過去のExcelデータ・これまでの対戦は「シーズン1」として保存されています。
- 画面上部の「シーズン」欄にある「＋ 新しいシーズンを開始する」を押すと、次のシーズンが始まります。
  以降の対戦は新しいシーズンに記録され、貯金・借金や各種統計もシーズンごとにリセットされて集計されます。
- シーズンのチップ（「シーズン1」「シーズン2」…）をタップすると、過去のシーズンの記録・統計を
  閲覧専用で見返せます（対戦自体は常に「現在のシーズン」に記録されます）。
- メンバー自体はシーズンをまたいで共通です（脱退・追加はシーズンに関係なく反映されます）。

## 貯金・借金（勝敗ポイント）の計算方法

1回の対戦ごとに、負けた人は「参加人数−1」ポイントを失い、
負けなかった人はそれぞれ+1ポイントを得ます（合計は必ずゼロになります）。
これは元のExcelの数値（上田+15・小林−11・吉村−4）と完全に一致する計算式です。

## ファイル構成

- `index.html` … 画面のHTML/CSS
- `app.js` … Firebaseとの通信・判定ロジック（過去データも埋め込み済み）
- `firebase-config.js` … Firebaseプロジェクトの接続情報
- `firestore.rules` … Firestoreのセキュリティルール（Firebaseコンソールの「ルール」タブに反映済み）
